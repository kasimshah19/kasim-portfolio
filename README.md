## 📌 Executive Summary

This repository contains the source code for my professional portfolio. It is not just a digital resume; it's a testament to modern web performance and visual design. Engineered using **React 19** and **Vite**, it balances heavy graphical lifting with lightning-fast load times, seamless micro-interactions, and robust serverless integrations.

## ✦ Technical Highlights

| Feature | Description |
| :--- | :--- |
| 🎬 **Cinematic Rendering** | Engineered with responsive video backgrounds for desktop pipelines while serving optimized static image fallbacks for mobile, ensuring 60FPS fluid scrolling. |
| ✨ **Fluid Micro-Interactions** | Integrated with `motion` (Framer) to power high-fidelity scroll animations, staggering reveals, and realistic spring-physics component interactions. |
| 📱 **Progressive Web Readiness** | Features a custom premium vector SVG graphics setup, fully scalable PNGs, and integrated `site.webmanifest` for cross-platform native alignment. |
| 📩 **Serverless Architecture** | Seamlessly integrated **EmailJS** to handle direct real-time inquiries straight from the UI to email, bypassing traditional backend server bottlenecks. |
| 🎨 **Premium Aesthetics** | Meticulously crafted dark-theme color contrast algorithms and precise Tailwind layout breakpoints to preserve structural and visual integrity on any device. |

## 🛠️ Technology Stack Breakdown

| Domain | Technology / Tooling |
| :--- | :--- |
| **Core Framework** | React 19, TypeScript, Vite |
| **Styling Engine** | Tailwind CSS v4 |
| **Animations** | Motion (Framer), GSAP Logic Principles |
| **UI Components** | Lucide React (Icons & Graphics) |
| **Communications** | EmailJS (Serverless Mail API integration) |
| **Deployment** | Vercel (Continuous Integration / CD pipelines) |

## 💻 Local Development Setup

Want to run or inspect this architecture locally? Follow these steps:

| Step | Action | Command |
| :---: | :--- | :--- |
| **1** | **Clone Repository** | `git clone https://github.com/kasimshah19/kasim-portfolio.git` |
| **2** | **Navigate workspace**| `cd kasim-portfolio` |
| **3** | **Install Packages** | `npm install` |
| **4** | **Env Variables** | Rename `.env.example` to `.env` & add your API keys |
| **5** | **Ignite Dev Server** | `npm run dev` |
